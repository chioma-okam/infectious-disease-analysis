# Cerebral Malaria Neuroprotection Pipeline

A professional computational biology workflow dedicated to the end-to-end downstream transcriptomic analysis of host immune responses during fatal cerebral malaria. This project specifically investigates the regulatory and neuroprotective effects of Methylene Blue on host redox systems.

## 📊 Dataset Profile
* **Source:** NCBI GEO
* **Accession ID:** [GSE265864](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE265864)

## 🛠️ Core Pipeline Workflows
* **Differential Expression Analysis:** Utilizing `DESeq2` for count data normalization, dispersion estimation, and isolating statistically significant differentially expressed genes (DEGs).
* **Functional Enrichment Profiling:** Implementing `clusterProfiler` to execute un-biased Gene Ontology (GO) terms and KEGG pathway mapping.
* **Data Visualization:** Leveraging `enrichplot` and `ggplot2` to generate high-density heatmaps, volcano plots, and enrichment dot plots.

## 🔄 Ongoing Work & Extensions
* **Network Visualization:** The downstream proteome interaction network coordinates generated by this pipeline are being prepared for advanced topological visualization and integration.
